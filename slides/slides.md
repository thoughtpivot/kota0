# Build with <span class="k0-accent">Kota0</span>

<p class="k0-hero__tagline">
Turn a product idea into a working, reviewable, deployable application.
</p>

---
layout: default
---

<div class="k0-step">
  <div class="k0-step__number">1</div>
  <div>
    <h2>Create an app</h2>
    <ul>
      <li>Choose <strong>New app</strong> from the app rail.</li>
      <li>Give the workspace a clear product goal.</li>
      <li>Kota0 creates an isolated frontend, backend, and runtime environment.</li>
    </ul>
    <div class="k0-callout">Each app keeps its own source, chat history, secrets, and deployment state.</div>
  </div>
</div>

---
layout: default
---

<div class="k0-step">
  <div class="k0-step__number">2</div>
  <div>
    <h2>Describe what to build</h2>
    <ul>
      <li>Use the AI panel to explain the audience, workflow, and desired outcome.</li>
      <li>Review the response and follow the streamed progress.</li>
      <li>Iterate with focused requests instead of rewriting the whole application.</li>
    </ul>
    <div class="k0-callout">Include real constraints: data sources, user roles, visual language, and success criteria.</div>
  </div>
</div>

---
layout: default
---

<div class="k0-step">
  <div class="k0-step__number">3</div>
  <div>
    <h2>Preview and inspect</h2>
    <ul>
      <li>Use <strong>Preview</strong> to interact with the generated app.</li>
      <li>Use <strong>Code</strong> to inspect or edit frontend and backend source.</li>
      <li>Resolve runtime and connectivity errors before shipping.</li>
    </ul>
    <div class="k0-callout">Generated code remains visible and reviewable throughout the workflow.</div>
  </div>
</div>

---
layout: default
---

<div class="k0-step">
  <div class="k0-step__number">4</div>
  <div>
    <h2>Deploy the result</h2>
    <ul>
      <li>Open the deployment panel after the preview is healthy.</li>
      <li>Deploy the current bundle as an isolated application process.</li>
      <li>Use the deployment URL to validate the production-shaped result.</li>
    </ul>
    <div class="k0-callout">Configuration stays environment-driven; app secrets are not embedded in source.</div>
  </div>
</div>
